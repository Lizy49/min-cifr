Как устроена проверка

Краулер читает публичные страницы, соблюдает robots.txt, сохраняет извлечённый текст, адрес, время загрузки, код HTTP и SHA-256 содержимого. JavaScript сайтов не выполняется. Обход ограничен числом страниц, файлов и временем.

Статусы

Пройдено — конкретная проверка дала положительный результат в загруженной выборке. Это не оценка всего сайта.

Замечание / проблема — найден признак нарушения или недоступный документ. Доказательства и ограничения приведены рядом.

Нужна проверка — данных недостаточно, раздел не распознан или вывод требует ручной сверки. Такой статус не считается подтверждённой ошибкой.

Новости и события

Даты извлекаются из schema.org, метаданных публикации и одиночного элемента time внутри статьи. Произвольная дата в тексте не считается датой публикации. Для интервала 24 часа нужны точные дата и время как публикации, так и события. Кварталы считаются по часовому поясу Магадана с учётом перехода года.

Самая свежая найденная публикация может не быть последней на всём сайте. Большой интервал между двумя загруженными статьями не доказывает отсутствие промежуточных публикаций.

Разделы и документы

Распознавание использует адреса и заголовки. Количество текста подтверждает только наличие содержимого. Полнота сведений о каждом сотруднике и актуальность образовательных программ требуют дополнительной проверки.

Загружается ограниченная выборка документов. PDF читается при наличии текстового слоя; сканированные страницы требуют OCR или ручной проверки. Для DOCX/XLSX текущая версия проверяет доступность файла. Перечни сравниваются по именам файлов и не являются нормативным списком обязательных документов.

ИИ и фактчекинг

ИИ — дополнительный модуль облачного GigaChat или локального Ollama. Сервис выбирается через AI_PROVIDER. Для GigaChat нужен ключ GIGACHAT_CREDENTIALS; состояние и проверка доступны в разделе «Подключение ИИ». При отключённом или недоступном ИИ приложение продолжает проверки по правилам и сообщает об ограничении.

Внешние источники задаются в карточке учреждения, до 5 URL. Приложение читает эти страницы; ИИ предлагает сопоставления. Автоматического поиска по всему интернету и окончательных выводов о ложности публикаций в версии 1.0 нет. Подсказки ИИ не меняют статусы правил.

Расписание и устойчивость

Очередь и расписания хранятся в MySQL. Пока процесс приложения работает, проверки выполняются последовательно. При перезапуске очередь сохраняется; зависшие запуски без обновления более 20 минут получают статус сбоя и могут быть запущены повторно. Для установки нужен один рабочий процесс краулера.

Источники требований

Школы и детские сады: «Описание проблемы», «Критерии оценки ИИ-краулер» и образовательная часть «Типичных ошибок заполнения». Колледжи и техникумы: дополнительный проектный чек-лист, согласованный по запросу команды. Приложение не выдаёт юридических заключений.

Доступ

Версия для локальной демонстрации не содержит многопользовательской авторизации. По умолчанию слушает только 127.0.0.1. Для доступа из сети нужны отдельная аутентификация, HTTPS и ограничения исходящих соединений.
