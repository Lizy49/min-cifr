# Проверка версии 1.0

Дата: 7 ноября 2026 года. Проверено на Windows, Python 3.12, MySQL Community Server 8.0.46, Waitress 3.0.2.

## Выполнено

- Создана отдельная MySQL на 127.0.0.1:3307 с собственным каталогом данных; существующая системная база не изменялась.
- Созданы четыре таблицы и отдельная учётная запись приложения. Подключение через SQLAlchemy/PyMySQL, русский текст UTF-8.
- Файлы `database/schema.sql` и `database/seed.sql` импортированы в отдельную тестовую MySQL-базу: все таблицы созданы, 87 записей загружены.
- Импортированы 87 записей: 40 школ, 40 детских садов, 4 колледжа, 3 техникума. Повторный импорт не создаёт дубликаты.
- Пройдено 37 автотестов: временные интервалы, неопределённые даты, переход года для кварталов, часовой пояс, даты карточек архива Госвеб, подпись даты статьи, старая русская кодировка, недоступные документы, robots.txt, блокировка локальных URL, CSRF, очередь, расписание, запись результата рабочим процессом, экспорт, экранирование HTML, нейтрализация формул CSV, явное отключение/ошибка ИИ.
- Реальная MySQL проверена отдельно от тестового SQLite: данные и результаты сохранены, после перезапуска веб-приложения доступны. Запись и чтение длинного русского текста LONGTEXT проверены транзакцией с откатом тестовой строки.
- HTTP /health возвращает `database: mysql`, `status: ok`. Реестр, история, сравнение, методика, добавление учреждения и отчёты возвращают HTTP 200. Проверены заголовки безопасности.
- Очередь запущена через настоящую веб-форму с CSRF, не прямой подстановкой заранее готовых отчётов.

Для колледжа и техникума зафиксированы отдельные 404 и ограничения robots.txt; запуск продолжился и сохранил эти ограничения. Отчёты, CSV и JSON всех четырёх запусков открываются. «Завершён» означает окончание обработки, а не отсутствие проблем на сайте.

При первом прогоне найдены и исправлены: ошибочная кодировка сайта колледжа и смешение даты страницы архива с датами отдельных публикаций. Добавлены регрессионные тесты. Для Госвеб поддержана дата статьи в специальной подписи рядом с заголовком; дата события в заголовке не используется как дата публикации.

## Что не проверено и не заявляется

- Физический запуск на Linux и сборка Docker в этой среде не выполнялись: Linux/Docker здесь отсутствуют. Поставлены переносимый Python-код, Linux-скрипт, Dockerfile и Compose; установленным зависимостям не нужны Windows API.
- Визуальная проверка скриншота браузером и диалога печати не выполнялась; HTTP-маршруты и шаблоны протестированы. Внешний вид реализован по согласованному макету и скриншоту портала.
- Локальная модель Ollama не установлена; настоящая генерация ИИ не тестировалась. Модуль реализован, отключение и сбой обработаны тестами. Живые результаты получены правилами, что явно показано в интерфейсе.
- Весь реестр одним прогоном не проверялся. Время обработки 87 учреждений зависит от доступности сайтов, лимитов и модели.
- Нет заявления о полном юридическом соответствии чек-листа СПО, безошибочном фактчекинге, полноценном OCR или промышленной многопользовательской эксплуатации.

## Исправление старых записей

Восстановлен текст 13 ранее сохранённых страниц запусков №3 и №7 (ошибочное прочтение Windows-1251 как Latin-1/CP866). Перед изменением создана резервная копия. Исторические статусы правил не пересчитаны; новые проверки используют исправленный декодер. Пустым источникам добавлены объяснения: HTTP-ошибка, отсутствие извлечённого текста или PDF без текстового слоя.

## Облачный GigaChat

Добавлен отдельный провайдер GigaChat с OAuth, кэшированием и обновлением токена, JSON-схемой ответа, сохранением подсказок и проверкой TLS. Новые тесты покрывают отсутствие ключа, авторизацию, кэш, обновление после 401, ошибки доступа/лимита, отсутствие утечки секретов, фильтрацию ссылок и ошибку сертификата. Проверка соединения получает только список моделей.

На запущенном приложении проверены /ai, POST формы с CSRF и честный статус «GigaChat · ключ не задан». Настоящая авторизация и генерация GigaChat пока не проверены: пользовательский ключ не предоставлен. Тесты API используют имитацию ответов, не выдаются за живой вызов.
