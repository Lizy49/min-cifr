Как подключить GigaChat

  1. Создайте проект GigaChat API в личном кабинете разработчика Сбера.
  2. Проверьте доступность бесплатной квоты именно для вашего аккаунта.
  3. Скопируйте Authorization key / ключ авторизации. Это не отдельный Client Secret и не временный access_token.
  4. Запустите в папке приложения python configure_gigachat.py и вставьте ключ в скрытый ввод терминала.
  5. Перезапустите приложение и проверьте соединение на этой странице.
  6. Запустите новую проверку учреждения: подсказки появятся в её разделе «ИИ-анализ».

При работе в виртуальном окружении используйте его Python. Можно внести ключ в GIGACHAT_CREDENTIALS файла .env и указать AI_PROVIDER=gigachat.

Если соединение не работает

Для ошибки сертификата задайте GIGACHAT_CA_BUNDLE — путь к доверенному PEM-файлу согласно инструкции Сбера. Проверка TLS не отключается. При ошибке доступа проверьте проект, scope, доступную модель и баланс.

При анализе в GigaChat передаются ограниченные фрагменты публичных страниц и заданных внешних источников. Ключ в браузер, отчёты и SQLite не передаётся. Подсказки остаются гипотезами; прежние отчёты автоматически не пересчитываются.
