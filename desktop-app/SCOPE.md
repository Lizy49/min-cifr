# Покрытие технического задания

| Требование | Реализация в desktop-app | Статус |
|---|---|---|
| Новости не реже одного раза в 2 недели | Структурированные даты последних новостей и интервалы в найденной выборке | Частично; полнота архива ограничена обходом |
| Публикация новости в течение 24 часов после события | Сравнение точных дат/времени, если обе даты присутствуют в структурированных данных | Частично; в остальных случаях требуется ручная проверка |
| Сверка новостей с открытыми источниками | До пяти внешних URL задаются пользователем для учреждения; страницы передаются выбранной модели ИИ для смысловых подсказок | Частично; автоматического поиска независимых источников нет, гипотезы требуют ручной проверки |
| Мероприятия текущего и следующего квартала | Извлечение структурированных дат и проверка кварталов | Частично; не все форматы календарей распознаются |
| Сопоставление мероприятий с новостями | Сопоставление по смыслу передаётся необязательному ИИ вместе с загруженными страницами | Частично; при выключенном ИИ специалист сверяет материалы вручную; результат ИИ не является вердиктом |
| Список обязательных документов | Обход ссылок на документы, доступность файлов, извлечение текста PDF при наличии слоя | Частично; нет полного нормативного справочника документов |
| Сравнение с эталонным сайтом | Выбор одного эталона для школ и одного для детских садов; сравнение имён обнаруженных файлов | Частично; результаты помечаются как гипотеза и требуют ручной сверки |
| Сведения о школе, руководство, педагоги | Поиск разделов по URL/заголовкам; сигналы по содержимому карточек | Частично; по каждой карточке требуется проверка |
| Контакты, режим работы, расписание | Проверка наличия телефона, почты, часов приёма и страниц расписания | Частично; актуальность значений не подтверждается |
| Детские сады: главная, новости, коллектив, программы, документы, «Педагогам и сотрудникам», контакты | Раздельный чек-лист для детского сада | Частично |
| Визуальные проблемы (логотип, баннер, фото, оформление) | Фиксируется наличие изображений; визуальная оценка выполняется человеком | Частично; автоматический визуальный анализ отсутствует |
| Понятный отчёт с проблемой, приоритетом, причиной и рекомендацией | Таблица результатов, объяснения, приоритет, доказательства и ссылки | Реализовано для правил первой версии |
| Экспорт отчёта | HTML и CSV | Реализовано |
| История проверок | SQLite | Реализовано |
| Проверка реальных сайтов, а не демонстрационных данных | Краулер получает публичные сайты в реальном времени | Реализовано; сетевой запуск из среды пользователя ещё надо проверить |
| Расписание проверок | Автоматический периодический запуск пока отсутствует | Не реализовано |
| Импорт ТЗ PDF/DOCX/TXT | Извлечение пунктов, тематическая классификация и распознавание явных числовых порогов; неоднозначные требования остаются на ручной проверке | Частично; черновик пока не заменяет встроенные правила аудита |
| ИИ-анализ | Необязательные провайдеры GigaChat и Ollama; вкладка состояния/тест соединения; подсказки с источниками и фильтрацией URL | Частично; реальный GigaChat требует ключ и доступную квоту, Ollama — установленную модель; облачная генерация не проверена без пользовательского ключа |

Неизвестный результат никогда не считается доказанным нарушением. Все выводы ограничены страницами, реально загруженными в ходе проверки.
