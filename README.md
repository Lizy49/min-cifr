Шаг 1: Создание SSH-ключа (делает каждый у себя в терминале)
Открой терминал и введи команду (замени почту на свою, привязанную к GitHub):
bash
1
Когда спросит Enter file in which to save the key — просто жми Enter (согласись на путь по умолчанию).
Когда спросит Enter passphrase — жми Enter (оставь пустым, чтобы потом не спрашивало пароль).
Когда спросит Enter same passphrase again — снова жми Enter.
Шаг 2: Копирование ключа (делает каждый у себя)
Выведи содержимое созданного публичного ключа на экран:
bash
1
Скопируй весь вывод, начиная с ssh-ed25519 и до конца (включая почту).
Шаг 3: Добавление ключа в GitHub (делает каждый у себя в браузере)
Зайди на GitHub под своим аккаунтом.
Нажми на свою аватарку справа сверху → Settings (Настройки).
В меню слева найди и нажми SSH and GPG keys.
Нажми зелёную кнопку New SSH key.
В поле Title напиши что угодно (например, "Ноутбук колледж").
В поле Key вставь то, что скопировал на Шаге 2.
Нажми Add SSH key.
Шаг 4: Переключение твоего репозитория на SSH (делаешь ты или каждый у себя в этом проекте)
Сейчас твой Git пытается стучаться по адресу https://github.com/.... Нужно сказать ему использовать SSH.
Проверь текущий адрес (ты увидишь там https):
bash
git remote -v
Замени адрес на SSH-формат (обрати внимание: в адресе должен быть владелец репо, в данном случае Lizy49):
bash
git remote set-url origin git@github.com:Lizy49/min-cifr.git
Проверь, что адрес изменился:
bash
git remote -v
Теперь там должно быть написано git@github.com:Lizy49/min-cifr.git.
Шаг 5: Проверка и пуш
Проверь соединение с GitHub (при первом разе может спросить Are you sure you want to continue connecting (yes/no)? — напиши yes и жми Enter):
bash
ssh -T git@github.com
Если всё ок, ты увидишь: Hi Lizy49! You've successfully authenticated...
Теперь спокойно делай push, никаких паролей спрашивать не будет:
bash
git push -u origin feature/maket
Резюме для твоих одногруппников:
Скинь им это сообщение. Им нужно сделать только Шаг 1, 2 и 3 на своих компьютерах. После этого они смогут клонировать репозиторий по SSH-ссылке (git clone git@github.com:Lizy49/min-cifr.git) и работать без всяких паролей.
Если на каком-то этапе вылезет ошибка — скидывай вывод сюда, разберём.
