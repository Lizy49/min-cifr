# 🚀 Инструкция по настройке и работе с репозиторием (Min-Cifr)

Эта инструкция предназначена для команды из 6 человек. Она описывает, как создать проект, настроить безопасный доступ без паролей и правильно работать с кодом, чтобы не мешать друг другу.

---

## 📂 Часть 1: Создание репозитория (Делает организатор)

1. Зайди на [GitHub](https://github.com) и нажми кнопку **New** (или «+» → «New repository»).
2. В поле **Repository name** напиши `min-cifr`.
3. Выбери **Public** (чтобы все видели) или **Private** (если код должен быть скрыт).
4. Обязательно поставь галочку **Add a README file**.
5. Нажми **Create repository**.
6. Перейди во вкладку **Settings** → **Collaborators** и добавь никнеймы всех 5 одногруппников. Они должны принять приглашение.

---

## 🔑 Часть 2: Настройка SSH-ключей (ОБЯЗАТЕЛЬНО ДЛЯ ВСЕХ 6 ЧЕЛОВЕК)

GitHub отключил вход по обычному паролю в терминале. Чтобы команды `git push` и `git pull` работали без постоянных запросов логина/пароля, нужно настроить SSH.

### Шаг 1: Генерация ключа
Открой терминал на своём компьютере и введи:
```bash
ssh-keygen -t ed25519 -C "твоя_почта@пример.com"
```
### Шаг 2: Копирование ключа
Выведи публичный ключ на экран:
```bash
cat ~/.ssh/id_ed25519.pub
```
<b> Скопируй весь текст, который появился в терминале </b> (от ssh-ed25519 до конца строки).

### Шаг 3: Добавление в GitHub
1. Зайди в свой профиль на GitHub → Settings.
2. Слева выбери SSH and GPG keys.
3. Нажми New SSH key.
4. В поле Title напиши что угодно (например, "Linux").
5. В поле Key вставь скопированный ключ.
6. Нажми Add SSH key.
### Шаг 4: Переключение репозитория на SSH
Если ты уже скачал проект по ссылке https://..., выполни эту команду внутри папки проекта, чтобы сменить протокол:
```bash
git remote set-url origin git@github.com:Lizy49/min-cifr.git
```

Замени `Lizy49` на никнейм владельца репозитория).
Проверить успех можно командой `git remote -v`. Там должно быть написано `git@github.com....`
